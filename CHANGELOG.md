# Changelog

Toutes les évolutions notables du projet **Farde** sont documentées dans ce fichier.

---

## [1.0.4] — 2026-08-11

### Ajouté

- affichage optionnel du titre sur chaque fiche ;
- commande globale pour afficher ou masquer tous les titres ;
- suppression directe des fiches depuis les boards ;
- option permettant de supprimer sans confirmation ;
- boutons Annuler et Rétablir disponibles sur iPhone ;
- réinitialisation complète du projet, des fiches, des images locales et des réglages ;
- recherche dans tout le classeur ou limitée à l’intercalaire actif ;
- case discrète à côté du champ de recherche pour choisir la portée de la recherche.

### Modifié

- simplification visuelle du contrôle de portée de recherche ;
- commentaires bilingues ajoutés aux nouvelles fonctions ;
- mise à jour du titre du projet depuis les réglages sur mobile.

### Corrigé

- recherche désormais insensible aux accents ;
- bouton Sauvegarder ZIP des réglages correctement relié à l’export ;
- amélioration du téléchargement ZIP sur iPhone ;
- correction du champ Titre du projet dans les réglages sur téléphone.

---

## [1.0.0] — 2026-08-01

Première version publique stable.

### Ajouté

- organisation du classeur en intercalaires thématiques ;
- création et modification de fiches illustrées ;
- import d’images locales ;
- titres, descriptions, tags et favoris ;
- recherche globale dans le classeur ;
- tri rapide et déplacement des fiches ;
- liaison des fiches Références avec les autres intercalaires ;
- affichage ou masquage des références liées ;
- focus image avec navigation ;
- diaporama du board actif ;
- export HTML autonome du diaporama ;
- export PDF ;
- sauvegarde et restauration par archive ZIP ;
- annulation et rétablissement ;
- interface bilingue français / anglais ;
- manuel intégré ;
- sauvegarde locale dans le navigateur ;
- favicon dédié ;
- documentation bilingue du code.
