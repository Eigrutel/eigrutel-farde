# Farde

**Bible graphique bilingue pour organiser les références visuelles d’un projet.**

Farde est une application web autonome développée dans le cadre d’**Eigrutel Lab**, l’atelier d’outils libres pour la bande dessinée d’**Eigrutel BD Academy**.

Elle permet de réunir dans un même classeur visuel les références, personnages, expressions, poses, costumes, objets, décors, palettes, indications de style, éléments de continuité et idées visuelles d’un projet.

## Fonctionnalités principales

- organisation par intercalaires thématiques ;
- création de fiches avec image, titre, description, tags et favori ;
- import d’images locales ;
- affichage du titre ou du texte court sur les fiches ;
- commande globale pour afficher ou masquer tous les titres ;
- recherche insensible à la casse et aux accents ;
- recherche dans tout le classeur ou limitée à l’intercalaire actif ;
- filtrage des favoris ;
- tri rapide et déplacement des fiches ;
- suppression directe depuis les boards ;
- option permettant de supprimer sans confirmation ;
- liaison des fiches de références avec les autres intercalaires ;
- consultation en plein écran et diaporama ;
- export PDF ;
- sauvegarde et restauration du projet au format ZIP ;
- Annuler / Rétablir sur ordinateur et iPhone ;
- réinitialisation complète du projet et des réglages ;
- interface bilingue français / anglais ;
- manuel intégré.

## Intercalaires disponibles

- Moodboard
- Références
- Idées visuelles
- Personnages
- Expressions
- Poses
- Costumes
- Objets
- Décors
- Couleurs / valeurs
- Style guide
- Continuité

## Utilisation

Farde ne nécessite aucune installation ni aucun serveur.

1. Télécharger `farde.html`.
2. Ouvrir le fichier dans un navigateur web récent.
3. Créer ou importer les fiches du projet.
4. Utiliser l’export ZIP pour sauvegarder ou transférer le classeur avec ses images.

Les données de travail restent enregistrées localement dans le navigateur tant qu’elles ne sont pas exportées.

## Sauvegarde et transfert

L’export ZIP est le format recommandé pour archiver un projet complet. Il conserve notamment :

- les fiches ;
- les intercalaires ;
- les textes et tags ;
- les favoris ;
- les liens entre références et boards ;
- les réglages ;
- les images locales.

## Langues

L’interface est disponible en français et en anglais.

Le changement de langue s’effectue dans **Réglages** avec le bouton `fr-en` / `en-fr`.
