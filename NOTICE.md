# Farde

Application web libre de création et de gestion de bibles graphiques.

Farde est un outil autonome permettant de rassembler, organiser, relier, consulter et présenter les références visuelles d’un projet : ambiances, personnages, expressions, poses, costumes, objets, décors, couleurs, continuité et idées visuelles.

Le programme fonctionne entièrement dans un simple navigateur web, sans installation ni serveur.

---

## Fonctionnalités

- Organisation des références par intercalaires.
- Création et modification de fiches illustrées.
- Import d’images locales.
- Utilisation de chemins ou d’URL d’images.
- Ajout de titres, descriptions et tags.
- Recherche globale.
- Favoris.
- Tri rapide et déplacement des fiches.
- Liaison des fiches Références avec les autres intercalaires.
- Affichage ou masquage des références liées.
- Focus image.
- Diaporama du board actif.
- Export HTML autonome du diaporama.
- Export PDF d’un board ou du classeur complet.
- Sauvegarde et restauration du projet par archive ZIP.
- Annulation et rétablissement des modifications.
- Interface bilingue français / anglais.
- Manuel complet intégré à la partie Infos.
- Sauvegarde locale dans le navigateur.

---

## Utilisation

Ouvrir simplement :

```text
farde.html
```

dans un navigateur moderne.

Aucune installation n'est nécessaire.

Pour transférer ou archiver un projet complet, utiliser l’export ZIP proposé par l’application.

---

## Compatibilité

Le programme est conçu pour fonctionner sur les navigateurs modernes :

- Safari
- Chrome
- Edge
- Firefox

sur ordinateur comme sur tablette.

Le comportement peut varier légèrement selon le navigateur, notamment pour l’impression, les téléchargements et le stockage local.
